# Leap Frogs Sprint 1 Project

This repository is the team workspace for the Leap Frogs sprint 1 project.

## Branching Strategy

We will use **Gitflow** as our branching strategy. This gives our team a clear structure for working on features, testing changes, and preparing stable code for release. Because several team members will be contributing over the project, Gitflow helps us stay organised and reduces the chance of people overwriting each other’s work.

In practice, we will keep the `main` branch for stable code, use a `develop` branch for ongoing integration, and create feature branches for individual pieces of work before merging them back in.
